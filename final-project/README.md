# Final Project

The culmination of CS50’s Introduction to Programming with Python.

## Requirements
- An original Python project implemented by you.
- Must include:
  - `project.py`: Containing a `main()` function and three or more standalone functions (each with accompanying tests).
  - `test_project.py`: Containing unit tests for your custom functions in `project.py` (executable with `pytest`).
  - `requirements.txt`: Listing any pip-installable libraries your project requires.
  - `README.md`: Explaining what your project does, how it works, and how to run it.

## Checklist
- [ ] Project idea decided
- [ ] Implement `project.py` with `main` and >= 3 custom functions
- [ ] Write unit tests in `test_project.py`
- [ ] Generate `requirements.txt`
- [ ] Document project in `README.md`
- [ ] Record and submit video demonstration
