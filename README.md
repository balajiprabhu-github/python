## 🛠️ Handy CS50 Commands

If using `cs50` command-line tools:

- **Style checking:** `style50 filename.py`
- **Correctness checking:** `check50 cs50/problems/2022/python/<slug>`
- **Submission:** `submit50 cs50/problems/2022/python/<slug>`
